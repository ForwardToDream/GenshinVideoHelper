# GenshinVideoHelper · 原神视频跟随助手

Windows 桌面小工具。让 B 站攻略视频通过 Chrome 原生画中画置顶在左下角，游戏中使用全局快捷键暂停、倒退和快进。

攻略示例：[BV1hjgG6jEa6](https://www.bilibili.com/video/BV1hjgG6jEa6)。选库后默认填入第一个视频；直接清空或改写地址即可自行输入。有效链接会自动预加载分集，选好分 P 后再开始跟随。

## 基础版功能

- 内置视频库：启动页点击“更换库”，在带搜索框的小窗口选择 UP 主 / 攻略库，启动页下拉选择地图视频；同时支持手动输入。
- 打开视频链接或 BV 号，使用独立 Chrome 配置目录，保留该目录内的登录状态。
- 选视频、输入有效链接或启动恢复链接时自动读取分 P 编号、标题和时长。开始前可预选分 P；跟随当前视频时直接在原标签页换集。
- 开始跟随或换 P 后，等待视频就绪，自动播放并进入左下角置顶画中画。
- “开始跟随”在分集控件下面独占整行；分集就绪时不显示额外说明，加载或错误时仍提供反馈。
- 手动开关浮窗；关闭后同一分 P 不会被轮询强制重开。
- 设置浮窗宽度并按视频比例调整高度，可直接拖动和缩放；普通轮询不会重新摆放浮窗。
- 程序窗口、任务栏与系统托盘使用统一原创图标；最小化收进托盘，右键可恢复或退出。退出会一并关闭助手的专用 Chrome 和画中画。
- 已开启的浮窗支持鼠标避让：四边各扩展 20% 的区域内隐藏，区域外显示；按住 ~ / 反引号键反转，松开恢复。主动关闭画中画后停止。
- 全局暂停/继续、后退/前进、上一集/下一集、静音、画中画及位置快捷键；九项绑定都可修改。
- 跳转步长 5 / 10 / 15 秒，播放速度 0.75 / 1 / 1.25 / 1.5 / 2 倍。
- 显示标题、播放状态和时间，保存所选视频库、最近跟随的分 P 链接、步长、宽度、快捷键开关与自定义绑定。

小地图识别尚未接入，预留了 `IMapLocator` 帧来源、时间戳和定位结果接口，参考源码在 `reference/BGI`。

## 主界面与设计参考

视觉参考 [Plain Craft Launcher（PCL）](https://github.com/Meloong-Git/PCL) 作者龙腾猫跃的默认蓝色标题栏、浅蓝背景、白色卡片和细描边控件。组织参考 Better Genshin Impact 的侧栏与卡片方式，按用户要求保留三个页面：

| 面板 | 用途 |
| --- | --- |
| 启动 | 地图视频下拉选择 / 手动链接、分集、自动跟随、播放控制及浮窗开关/定位；分集下面整行“开始跟随”，就绪状态不显示说明行 |
| 快捷键 | 全局开关、九项操作说明、绑定编辑 / 按键录入、占用提示、保存与恢复默认 |
| 设置 | 步长、倍速、浮窗宽度、根目录配置路径，使用说明与 PCL/BGI 署名 |

攻略卡片标题区分两行：上方为“攻略选择”和右侧“更换库”，下方为库 / UP 主摘要与视频数量。不额外显示“Px / 共…集”，分集信息保留在下拉框中；读取失败时在错误提示旁提供重试。

窗口默认 1020 × 730，最小 860 × 600，内容区独立滚动。切换面板不会重置视频会话或停止快捷键；编辑快捷键时临时停用，离开输入框恢复。设计约定见 [AGENTS.md](AGENTS.md)，研究见 [PCL UI 笔记](reference/PCL-notes.md)。本项目保留独立名称和实现，与参考项目官方无关联。

## 使用

运行环境：Windows 10/11、桌面版 Google Chrome、.NET 8 Desktop Runtime。源码构建需要 .NET SDK 8 或以上。

双击根目录 `start.cmd` 运行发布版本；没有发布包时会尝试源码启动。也可执行：

```powershell
.\scripts\run.ps1
```

1. 在启动页点击“更换库”，搜索并确认视频库，默认填入该库第一条视频。下拉选择地图或直接清空 / 改写地址输入链接或 `BV...`，分集会自动加载；选好分 P 后点击“开始跟随”。带 `?p=3` 的链接会选中 P3，未指定时从 P1 开始。
2. 工具打开专用 Chrome 窗口，视频就绪后自动播放并进入左下角画中画。需要登录、验证或网站操作时，请在 Chrome 中完成；工具会显示等待提示。清晰度也在浏览器内选择。
3. 使用分集下拉框或上一集/下一集切换攻略段落，工具复用原标签页并恢复自动跟随。在浏览器手动换 P 也会同步面板。
4. 自动跟随失败可点击“重试自动跟随”。分集读取失败可点击“重试分集”，播放控制仍可使用。
5. 最小化工具后收进系统托盘，浏览器、浮窗和快捷键继续运行；双击托盘图标或右键选择“显示主界面”恢复。进入游戏，用 Alt+1/2/3 控制。推荐无边框窗口模式。

分集示例：[P3 · 古兽冰原1-7](https://www.bilibili.com/video/BV1hjgG6jEa6/?p=3)。`p` 指定分 P，`spm_id_from` 不参与选择。工具保存分 P 链接，不记录逐集播放进度，也不额外改变网站连播策略。

多屏使用时，先把工具移到游戏所在屏幕，再点击“放回左下角”。在设置页修改宽度后也用这个按钮应用；下次自动开启浮窗会使用新宽度。

| 快捷键 | 操作 |
| --- | --- |
| Alt + 1 | 后退一个步长，默认 5 秒 |
| Alt + 2 | 暂停 / 继续 |
| Alt + 3 | 前进一个步长，默认 5 秒 |
| Alt + Left（←） | 上一个分集，首集不切换 |
| Alt + Right（→） | 下一个分集，末集不切换 |
| Alt + P | 开启 / 关闭画中画 |
| Alt + Home | 放回左下角并应用设置宽度 |
| Alt + End | 静音 / 恢复声音 |
| 按住 ~ / 反引号键 | 反转浮窗隐藏状态，松开恢复；仅已开启的画中画生效 |

以上为默认绑定，数字键指主键盘数字行，没有小键盘别名。在独立“快捷键”页手动填写如 `Alt+Left`、`Ctrl+Shift+F8`，或点击“录入”后按组合键，Esc 取消录入；点击“保存绑定”立即应用。支持 Ctrl / Alt / Shift / Win 加字母、主键盘数字、F1–F24、方向键及 Home / End 等常用键。编辑输入框期间临时停用全局键，离开后恢复已保存绑定。重复或无效组合不能保存；“填入默认绑定”也需保存后才生效。被其他程序占用的键在此页单独提示，其余键继续生效，可改组合再保存。退出工具会释放快捷键，并关闭助手专用的 Chrome 和画中画；正常使用的其他 Chrome 配置不受影响。

鼠标避让只临时隐藏已开启的浮窗，隐藏时视频继续播放，鼠标可穿过原浮窗位置，恢复时不抢焦点。移动或调整浮窗大小后，检测范围随之更新；助手最小化时仍然生效。默认按住主键盘 Esc 下方的 ~ / 反引号键反转当前隐藏结果，无需 Shift。在“快捷键”页可改绑单键或组合键，保存后立即生效；关闭全局快捷键或编辑绑定时，反转键暂时停用，自动鼠标避让继续运行。主动关闭画中画后，移动鼠标或按反转键不会重新开启；再次打开后恢复避让。退出助手时先停止鼠标避让，再关闭专用 Chrome 和画中画。

画中画依赖原视频页面，请保留标签页。手动关闭浮窗后可用按钮或 Alt+P 重开；打开另一个视频或换 P 会恢复自动流程。同一分 P 刷新页面导致浮窗关闭时，可重开或点击重试自动跟随。

原生画中画只显示视频画面，网页弹幕和网页叠加字幕通常不会进入浮窗。独占全屏游戏可能遮住浮窗，请改为无边框窗口。当前支持普通 B 站网页点播视频，短链接需先转换为完整视频地址。

## 视频库

首个内置库为 **汉卿导航 · 每张地图完全从零开始**，UP 主空间：[汉卿导航](https://space.bilibili.com/3546597013064142/)。按用户提供的清单收录 22 个地图攻略视频，从“蒙德、璃月、龙脊雪山”到“至冬·其之一”。视频库条目选择整套视频，下面的分集下拉框选择该视频里的 P，两者独立。

在启动页点击 **更换库**，直接打开独立的库选择小窗口。搜索支持库名、UP 主、地图名称及 BV 号，也支持空格分隔的多个关键词。选中库并点击“使用此库”后更新候选列表并填入第一条视频；取消或关闭窗口会保留原库。无匹配结果时显示提示且不能确认，清空搜索可恢复全部列表。选中地图仅填入地址，点击“开始跟随”后才打开；更换库不会打断正在播放的视频。视频下拉框仅展示库中的实际视频，不再包含“自行输入”选项；直接清空或编辑地址即可输入其他链接，也可指定 `?p=N`。手动地址与库中视频匹配时自动选中对应地图，否则地图选择留空。

库名、UP 主、空间链接、说明和有序的视频条目独立存放在 [hanqing-zero-start.json](src/GenshinVideoHelper.Core/Library/Data/hanqing-zero-start.json)，发布时嵌入 Core，离线即可加载列表。后续增加库时在 `src/GenshinVideoHelper.Core/Library/Data` 新增同格式 JSON，使用唯一 `Id`，重新编译 / 发布即可自动进入选择列表。当前只收录用户提供的这个库，不自动抓取或补充其他 UP 主视频。

配置中的 `SelectedVideoLibraryId` 记住库选择；值为 `null` 表示不使用库。库默认地址取第一条视频，不增加默认链接配置字段；启动时优先恢复所选库内最近跟随的视频与分 P，否则填入第一条。未使用库时恢复最近的手动地址。加载链接只读取分集，不会自动打开 Chrome 或开始播放。库名、UP 主入口、说明与视频数量在库选择窗口呈现。

分集预览通过 B 站接口读取；正在跟随同一视频时优先读取页面元数据。手动输入采用短暂延迟，避免逐字请求；同一视频的分集在本次运行中缓存，快速改选会取消旧请求并校验版本。读取失败显示“重试分集”，仍可直接开始跟随。准备其他视频或预选其分 P 不打断当前播放；全局上一 / 下一集快捷键始终控制正在跟随的视频。

## 浏览器与分集连接方式

通过 Chrome DevTools Protocol 控制选中的 B 站标签页，不需要浏览器插件。分集优先读取页面元数据，缺失时使用 B 站视频信息接口；网站数据结构变化或接口不可用时会显示分集读取错误并提供重试。

专用浏览器配置位于 `%LOCALAPPDATA%/GenshinVideoHelper/Chrome`。应用设置改为根目录 `GenshinVideoHelper.settings.json`，首次运行自动生成；不读取或迁移旧名称的配置与浏览器目录。控制端口使用随机端口和本机回环地址。已有日常 Chrome 窗口不会自动连接，见 [Chrome 官方远程调试说明](https://developer.chrome.com/blog/remote-debugging-port)。浮窗由 Chrome 原生 API 创建，位置通过 Windows 窗口 API 调整。

## 根目录配置

`GenshinVideoHelper.settings.json` 包含以下字段：

| 字段 | 含义 |
| --- | --- |
| `SelectedVideoLibraryId` | 所选视频库的稳定编号，默认 `hanqing-zero-start`；`null` 关闭库 |
| `VideoUrl` | 最近跟随的实际分 P 链接；切换分集后更新 |
| `SeekSeconds` | 前进 / 后退步长（秒） |
| `PipWidth` / `PipMargin` | 浮窗宽度 / 左下角边距 |
| `HotkeysEnabled` | 全局快捷键是否启用 |
| `Hotkeys` | 九项操作对应的绑定，例如 `PreviousEpisode: "Alt+Left"`、`ReversePipVisibility: "~"` |

从 `start.cmd`、源码或发布目录启动都定位到同一根目录配置。单独拷贝发布目录作为便携版时，配置生成在 exe 同目录。配置可在软件关闭后手动编辑，下次启动读取；格式错误会显示提示并暂用默认设置，下一次保存前备份原文件为 `.bak`，不会直接丢弃原内容。测试使用独立文件，不写入这份配置。

已移除默认视频链接机制，旧配置里的 `DefaultVideoUrl` 不再读取，保存时会移除这个字段；最近跟随地址 `VideoUrl`、库选择及其他偏好继续保留。Chrome 登录状态保存在 `%LOCALAPPDATA%/GenshinVideoHelper/Chrome`。
