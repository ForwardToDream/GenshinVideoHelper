# GenshinVideoHelper

边玩原神，边跟 B 站攻略。画中画看视频，小地图看指导位置。

## 下载

在 [GitHub Releases](https://github.com/ForwardToDream/GenshinVideoHelper/releases) 下载 `GenshinVideoHelper.exe`，直接运行。

需要 **Windows 10 2004 或更新版本 / Windows 11（64 位）**、**Chrome 或 Edge**，以及 [.NET 8 Desktop Runtime（Windows x64）](https://dotnet.microsoft.com/zh-cn/download/dotnet/8.0)。已安装则无需重复安装；请选择“桌面运行时”。

未安装时，启动 exe 会提示安装，并提供官方下载入口。安装后重新打开助手。

## 使用

1. 打开原神，建议使用无边框窗口。
2. 在助手的“启动”页选库、选地图，或直接输入 B 站视频链接 / BV 号。
3. 选择分集，点击“开始跟随”。视频自动播放；画中画首次默认放在左下角，以后恢复保存的位置。
4. 切回游戏，用快捷键控制视频。

每次只跟随一个视频。换视频会替换当前播放；选择正在跟随的视频分集会直接换集。

默认手动输入。首次启动可选择一个合集库，也可保持手动输入；以后不再提示。随时可点击“更换库”调整。

手动跟随的链接保存在地址框右侧的历史下拉中，最近优先；点垃圾桶后再点确认图标删除。合集跟随不记历史。

选择合集库后显示第一个视频。再次选择地图，会定位到未完成分集，并按已保存的续播点继续。

### 画中画

拖动视频或横条移动，拖动边缘调整大小；位置和大小自动记忆。Alt+Home 放回左下角。

默认鼠标靠近时隐藏，离开时显示。Alt+4 依次切换：**锁定显示 → 强制隐藏 → 鼠标避让**。

关闭浮窗后，用 Alt+P 重新开启。最小化助手会收进托盘，双击托盘图标恢复；退出助手会关闭它的浏览器和浮窗。

### 地图与进度

- **地图识别**：默认开启，在用户小地图上标记指导位置；视线可信时显示方向。游戏使用默认小地图布局，攻略小地图应在视频左上区域（左 1/3、上 1/2），两端需有重叠地形。建议攻略使用 1080p。切出游戏时隐藏标记。
- **识别频率**：在“地图识别”页调整，默认 100ms；选择 150–200ms 更省 CPU。短暂采集延迟或失配会保留上次标记。
- **观看进度**：只累计实际播放过的区间，跳过部分不算已看；默认覆盖 90% 才完成。在“进度”页可修改已看区间、续播点及完成状态，也可撤销修改。

## 快捷键

| 按键 | 操作 |
| --- | --- |
| Alt+1 / Alt+2 / Alt+3 | 后退 / 暂停继续 / 前进 |
| Alt+← / → | 上一集 / 下一集 |
| Alt+P | 画中画开关 |
| Alt+Home | 放回左下角 |
| Alt+End | 静音开关 |
| Alt+4 | 切换浮窗显隐模式 |

在“快捷键”页修改绑定；在“设置”页修改跳转步长、倍速和浮窗宽度。默认跳转 5 秒。

## 常见问题

| 问题 | 处理 |
| --- | --- |
| 视频画质低，或提示未登录 | 选择“去登录”，在助手的浏览器中登录。助手会尝试请求 1080p；实际画质取决于视频和账号权限。 |
| 自己的浏览器已登录，助手仍提示登录 | 助手使用独立浏览器配置，Chrome 与 Edge 也分别保存登录状态。 |
| 想换浏览器 | 在“设置”页选择。自动优先 Chrome，再选 Edge；改选在下次“开始跟随”生效。 |
| 快捷键无效 | 在“快捷键”页查看占用提示，启用全局快捷键，或换一个绑定。建议直接用默认键位。 |
| 地图没有标记 | 查看“地图识别”页状态，确认游戏在前台、小地图可见、布局为默认；让两端靠近同一区域，并提高攻略画质。 |
| 浮窗不见了 | 用 Alt+4 切换到锁定显示；已关闭时用 Alt+P 开启，再用 Alt+Home 复位。 |

## 更新与备份

每次启动会在后台检查正式版本。有新版时，版本号左侧显示红色“可更新”，点击打开下载页；也可在“设置”页手动检查。

退出助手后，用新版 exe 覆盖旧文件，保留同目录的 `.gvh/`。

`.gvh/` 保存设置、快捷键、观看进度和浏览器登录状态。备份或搬动程序时一起带走。
