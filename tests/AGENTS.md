# 测试

- 根目录执行 `scripts/test.ps1`；专项参数见 [测试说明](../docs/testing.md)。
- 测行为与边界，不复制实现；不以吞异常、改期望或放宽无关阈值解决失败。
- `Fixtures/Minimap/basic/` 的 8 张图片与固定期望随 Git，普通测试必跑；缺图失败。
- `full/` 仅本地，存在即测；坏图、缺文件失败，整个目录不存在才跳过。原始录像不作基础测试依赖。
- 用 `TestArtifacts` 在 `artifacts/test-run` 建独立目录；清理前验证绝对路径范围。
- 浏览器用独立配置，禁止复用或关闭个人浏览器；公共能力分别测 Chrome / Edge。
- 离线、模拟、真实游戏验证分别报告；未联调不宣称实测通过。
