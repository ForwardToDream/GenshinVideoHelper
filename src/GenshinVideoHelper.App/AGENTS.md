# App

- PCL 视觉、BGI 面板组织，复用 `Resources/PclTheme.xaml`。
- 侧栏：启动、进度、地图识别、快捷键、设置；启动页只放攻略选择与播放控制。
- 选库弹窗带搜索，选视频预加载分 P；开始跟随在分集下方独占一行。
- 浏览器卡片高度固定，安装名称、版本、路径放下拉列表；标清当前与待生效选择。
- 一个 WPF 蓝色外框用 DWM 合成浏览器画面；不逐帧截图显示、不改源窗口父级。
- 视频和横条整体移动、缩放、显隐；Alt+4 单次循环锁定显示、强制隐藏、鼠标避让，避让范围扩展 20%。
- 手动关闭后当前自动流程不重开；按项注册热键，报告冲突、保留成功项、关闭释放。
- 完整外框布局以屏幕物理像素记忆，拖动缩放合并写入，恢复时约束工作区；首次左下角，复位会记忆，自动操作不覆盖用户布局。
- 地图默认开启、跟随后绑定原神、默认 100ms；WGC 在 GPU 裁固定用户地图，标记不抢焦点。
- 最小化到托盘；退出先隐藏，再并行刷新数据与清理专用浏览器，预算 2.5 秒。
- 启动后台检查正式 Release，失败不打断跟随；退出取消请求，仅用户点击后打开下载页。
- 检查默认 / 最小尺寸、长标题、下拉及错误态；浮窗修改补 Chrome / Edge 验证。见 [测试](../../docs/testing.md)。
