# 视觉算法

- 先读 [视觉流程](../../../docs/vision.md)；参数以实现为准，回归使用固定样本。
- 用户圆盘固定：1080p 圆心 `(168,125)`、半径 `106`，按 client 高度缩放；不检测用户箭头或圆盘。
- 攻略唯一 `arrow_first`：原生视频左 1/3、上 1/2，青色箭头定圆心，再找有半径下限的完整圆；兼容放大与 360° 旋转，不拟合椭圆或追加检测器。
- 两盘归一化，ORB 匹配地形并投影攻略圆心；箭头不是配准目标，不使用 SIFT 或世界地图库。
- 视线取白色扇形；方向不可信仍显示位置点，标记颜色兼顾局部对比与稳定性。
- 相同攻略帧复用归一化图和 ORB 特征；找到圆盘后局部无损采集，不截缩小的画中画。
- 暂时失配与明确无效分别表达保留、撤销；不加固定帧年龄或标记过期机制。
