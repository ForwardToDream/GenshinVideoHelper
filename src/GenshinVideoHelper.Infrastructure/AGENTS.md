# Infrastructure

- Chrome / Edge 共用 Chromium / CDP；自动按安装状态优先 Chrome，加载失败不换浏览器。
- 改选在下次开始跟随生效；换 P、快捷键和登录使用当前会话。
- 后台预热、最小化加载，不抢焦点；复用 CDP 连接，媒体事件驱动、轮询补偿。
- 只保留一个视频标签页；再次跟随和换集复用。保存创建后的目标 ID，取消不得遗留额外视频页。
- 媒体就绪后分别确保播放和画中画；明确匿名才提示登录，换 P 不重复提示，高清以实际解码尺寸为准。
- 切换先撤销旧请求、浮窗和标记，再异步清理；复用同一配置前等待旧会话退出。只关闭身份验证过的助手进程。
- 数据路径统一用 `ApplicationPaths`，根目录为 exe 同目录 `.gvh/`；Chrome / Edge 配置隔离。
- 视频库只从 `.gvh/libraries/` 读取；内置 JSON 仅首次生成，已有库不覆盖、不补回。编辑保持 ID，保存后刷新目录与列表。
- JSON 走现有存储服务，替换写入并保留坏文件、备份；日志走 `AppLog`，有界、滚动、去重，不记 Cookie 或页面正文。
- 算法约束见 [Vision/AGENTS.md](Vision/AGENTS.md)；完整说明见 [开发](../../docs/development.md)。
